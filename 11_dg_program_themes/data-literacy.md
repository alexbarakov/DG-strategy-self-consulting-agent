# Data Literacy

## What the board teaches
The board's dedicated Data Literacy section is carried almost entirely by images (6 screenshots/diagrams, not machine-readable) — for the actual material open the deep-link below. The machine-readable substance lives in two adjacent places. First, the Data-Driven Index dashboard details a Data Literacy scoring model: role skill profiles with target levels L1-L4, individual and team/department skill scores, and an aggregated skill-level score vs target across ~13 named skill dimensions; Data Literacy also carries the highest weight (0.15) among DDI components. Second, the Program Map 3.0 positions data literacy as stream 4.8: hiring data-literate employees, a D&A competency matrix for key roles, and a modern learning system (onboarding, mandatory/group training, marathons, skill belts, community gamification).

## Key objects
- Data Literacy section frame: title + 6 unextracted images (stub — visual-only content)
- L1-L4 skill scoring: role skill profiles with targets; individual / team / aggregated scores vs target
- Skill dimensions: data interpretation, data visualization, critical thinking, data-driven decision-making, data storytelling, trend analysis, basic Excel, BI tool proficiency, basic SQL, data privacy awareness, cognitive-bias identification, DG awareness, AI ethics
- DDI weighting: Data Literacy = 0.15, tied for the highest component weight (see [maturity-and-metrics.md](maturity-and-metrics.md))
- Program Map stream 4.8: data-literate hiring, competency matrix, learning system (onboarding, marathons, skill belts, gamified community)

## From the course (Data Governance Fundamentals, 6 days)

- The author deliberately avoids DAMA/DMBOK/Kimball language with business: "not because they are wrong — but this language gets in the way of talking to business, and even data-analytics management is usually far from pure architecture." (course day 5, transcript)
- Professional jargon itself is a misalignment source in large teams: one person says measures, another metrics, a third indicators — vocabulary divergence inside the data function is a literacy problem before any business training starts. (course day 5, transcript)
