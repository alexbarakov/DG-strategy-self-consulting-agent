## Summary
Author's opinion slide addressing DG skepticism. On buzzword criticism: assess maturity, size, and business specifics before investing; start simple and add complexity gradually (references the Stage 1-3 prioritization framework). On "what's the point of DG": it is an organizational and tooling coordination layer — the DG team drives strategy, the DG MVP, and cross-team synchronization (data platform, data engineers, core BI, data stewards). The right column traces evolution without a dedicated DG team: DWH/BI leads handle governance informally ("DG common sense" = standardized data lifecycle ops + basic DQ + BI reporting metrics), which breaks down at scale, creating the inflection point that requires a formal DG MVP or project team.
