## Summary
Reference frame describing the role model of a Data Governance organization, split into DG Office (central) roles and business-side roles, with detailed responsibility lists for Executive Sponsor and Data Custodian. Executive Sponsor is framed as a senior business leader (not technical) with ultimate accountability for a data domain; Data Custodian is the IT/technical counterpart (DBAs, ETL developers, data engineers, BI professionals) whose responsibilities largely mirror those teams' existing day-to-day work. Connectors show delegation/relationship flows between roles.

## Objects
- Title: "DG Role Structure"
- DG Office roles (purple-highlighted cluster): CDO, Data Governance Lead, Coordinating Data Steward, Tools Development Team (DataCatalog, DQ Tool)
- Business-side roles: Executive Sponsor, Business Data Steward, Data Owner, Data Custodian
- Executive Sponsor responsibilities: ultimate accountability for domain decisions; oversight of data definitions/policies; compliance with quality, accuracy, relevance, audit requirements; approval of all domain policies; arbitration between domains; working sessions on policy violations
- Data Custodian responsibilities: managing/controlling data access; data integrity via technical processes; resolving DQ issues with the Data Steward; technical data protection; verifying new data against common data models; maintaining master data versions and change history; change management for database maintenance; verifying data content and changes
- Note: custodian tasks reflect the typical day-to-day work of existing teams
- Solid and dotted connectors between roles and detail blocks
