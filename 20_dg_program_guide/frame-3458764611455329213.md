## Summary
A Data-Driven Index (DDI) framework template for measuring an organization's data maturity as a single weighted composite score: DD Index = sum(weights x Component). A 26-row scoring grid lists components, example metrics, calculation complexity (Low/Middle/High), formulas, current values, weights, and weighted contributions; weights sum to 1.00 and the example total score is 62.99. The frame is explicitly a template — metrics and weights should be tailored to what a company can effectively calculate and what is meaningful for its business.

## Objects
- Formula block: Data-Driven Index = sum(weights x Component)
- 26x7 scoring grid: Component / Metric Example / Complexity / Formula / Metric Value (%) / Weight / Metric x Weight
- 13 components with weights: Data Literacy (0.15), Tools Adoption (0.15), Organisational Model (0.09), Data Management (0.12), Direct Business Value (0.13), Data Accessibility (0.12), Analytics Maturity (0.03), Culture (0.06), Innovation (0.03), Customer Insights (0.03), Data Security (0.03), Data Infrastructure (0.03), Leadership (0.03)
- Example totals: DD Index = 62.99; weakest metrics — NPS improvement (10%), cost reduction from data decisions (14%), revenue from data decisions (44%); strongest — infrastructure uptime (99%), ad-hoc duration (95%), data access efficiency (90%)
- Advisory note: choose metrics by feasibility and business meaning
