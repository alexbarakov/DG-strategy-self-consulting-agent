## Summary
A structured problem-to-solution mapping canvas for transformation planning, using the example "The supply chain processes are inefficient for the new product and require digital transformation." Flow runs left to right: a problems tree (yellow stickies, solid arrows for problem hierarchy/decomposition) maps via dotted arrows onto a solutions grid (green stickies), and selected solutions are then bundled into three initiative containers (blue dashed rectangles) — i.e., problem decomposition → solution mapping → initiative packaging. All stickies are blank; it is a reusable template demonstrating the method.

## Objects
- Header example statement (supply chain / digital transformation)
- Problems tree: root problem branching into sub-problems and sub-notes (yellow stickies, solid curved arrows)
- Solutions grid: green stickies receiving dotted arrows from problem nodes
- Initiative 1 / Initiative 2 / Initiative 3: blue dashed grouping rectangles, each bundling 3-4 green solution stickies
- Visual conventions: yellow = problems/causes, green = solutions, solid arrows = problem hierarchy, dotted arrows = problem-to-solution mapping, dashed containers = initiative bundles
