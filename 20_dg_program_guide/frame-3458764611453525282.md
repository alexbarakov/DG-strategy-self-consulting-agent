## Summary
Educational section on Data Governance frameworks. Defines a DG framework (per the Data Governance Institute: "a logical structure for classifying, organizing, and communicating the complex activities associated with enterprise data decision-making and action-taking"), presents two reference frameworks — DGI's ten-component model (rules / people / processes, including Goals-Metrics-Funding, Controls, and the DG Office) and PwC's four-layer Enterprise Data Governance Framework (from the embedded "Demystifying Data Governance" 2019 PDF) — and gives a three-step recipe for creating your own framework. Explicitly warns that a framework is an abstract model, not yet an implementation project.

## Objects
- Section header: "DG frameworks"
- DG framework definition (DGI quote)
- DGI Data Governance Framework: 10 universal components across rules, people, processes; Goals/Metrics/Funding, Controls, Data Governance Office (DGO)
- PwC Enterprise Data Governance Framework (embedded PwC PDF "Demystifying Data Governance", Nov 2019): Data Management; Enablers (People & Culture, Process & Operating Model, Tools & Technology); Stewardship & Core Layer (Stewardship, Lineage, Glossary, Master Data, Metadata, Quality & Trust, Access & Ownership, Privacy & Security); Governance Strategy & Vision (Control/Efficiency vs Growth/Monetization)
- "How to create your own DG framework": (1) study existing frameworks, (2) draft focus areas — core elements vs org-specific priorities vs exclusions, (3) sketch it with the team in a half-day session
- Caveat note: "This is not yet a data governance implementation project; it's an abstract model of how it will work"
