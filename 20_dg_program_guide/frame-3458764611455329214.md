## Summary
A dashboard mock-up showing how one component (Data Literacy) rolls up into a company-level composite index. The frame is built from ~180 small coloured rectangles forming three separate L1-L4 grids, plus four text/card labels, three person icons, one department icon and one meme image. Reading order is bottom-up: individual skill scores → team/department scores → "Aggregated Data Literacy Skill Levels Score vs Target" card → "Company Data-Driven Index" card.

Top right carries the formula **Data-Driven Index = ∑ (weights × Component)** with the grey caveat "Exact formula should be developed specifically for your company", and a second grey caveat next to the Data Literacy block: "Final components and metrics list depends on what you can effectively calculate and what is meaningful for your business." Footer: data-nature.com.

## Objects

### KPI card — "Company Data-Driven Index" (teal card, `#0ca789`)
Big number **62,9** in navy, secondary number **11,1** with the caption **"vs Last Year"** and a small trend icon between them. A dotted arrow feeds this card from the "Aggregated Data Literacy Skill Levels Score vs Target" card, and a second dotted arrow feeds it from another aggregate block — i.e. the index is assembled from component-level aggregates.

### Middle grid — "Individual DL skills score"
Three stacked 6-row × 4-column blocks, one per person (each block has a person avatar icon to its left). Cells use three states: dark blue `#1988dc` = level achieved, light blue `#6fbaf4` = level partially achieved / in progress, grey = not achieved. The rows are unlabelled in this mock-up — the skill names are only spelled out in the left grid. Reading the fill pattern:
- Person 1 (rows top to bottom): dark/light/grey; dark/dark/light; dark/dark/dark; dark/light/grey; dark/dark/dark; dark/light/light. Column L4 grey for all six rows.
- Person 2: dark/light/grey; dark/dark/light; dark/dark/dark; dark/dark/grey; dark/dark/grey; dark/dark/grey. L4 grey throughout.
- Person 3: light/light/grey; dark/dark/dark; dark/dark/dark; dark/dark/grey; dark/light/grey; dark/grey/grey. L4 grey throughout.

### Right grid — "Team / Department DL skill scores"
A single 6-row × 4-column block (larger cells) with a department icon. Three arrows run from the L4 column of each of the three individual blocks into this department icon, i.e. individual scores aggregate into the team/department score. Fill pattern per row: dark/dark/grey; dark/dark/grey; dark/dark/dark; dark/dark/light; dark/dark/grey; dark/dark/grey — again nothing reaches L4.
