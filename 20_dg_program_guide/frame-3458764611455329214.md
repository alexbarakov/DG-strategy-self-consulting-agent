## Summary
A dashboard-style mockup for measuring an organization's data-drivenness via a composite "Company Data-Driven Index" (example value 62.9, +11.1 vs last year) computed as a weighted sum of components: Data-Driven Index = Σ(weights × Component). The exact formula "should be developed specifically for your company" and the final component/metric list "depends on what you can effectively calculate and what is meaningful for your business". A Data Literacy component is detailed: role skill profiles with target levels L1-L4, individual and team/department DL skill scores, and an aggregated skill-level score vs target. By Data Nature (data-nature.com). Much of the visual (charts, gauges) is carried by shapes/images — open the deep-link for the layout.

## Objects
- Company Data-Driven Index card: 62.9, +11.1 vs Last Year; formula Σ(weights × Component); note that formula and component list are company-specific
- Data Literacy component: role skill profiles with target levels (L1-L4 scale); Individual DL skills score; Team/Department DL skill scores; Aggregated Data Literacy Skill Levels Score vs Target
- Data literacy skill dimensions: Data Interpretation; Data Visualization; Critical Thinking; Data-Driven Decision-Making; Data Storytelling; Trend Analysis; Basic Excel Skills; BI Tool User Proficiency; Basic SQL Querying; Data Privacy Awareness; Identifying Cognitive Biases; Data Governance Awareness; AI Ethics; "..."
