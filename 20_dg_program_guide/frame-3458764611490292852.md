## Summary
A mind map blueprint of a company-level Data Governance program built around three linked root nodes: DG Vision (a short version of the DG framework), Your DG Framework (central hub with 10 numbered branches), and Funding and Executive Support. The 10 branches enumerate everything a DG framework should define — from key terms and program goals through role model, cost-benefit model, policy, technology stack, and communication system. The chain of roots implies Vision informs the Framework, which requires Funding and Executive Support.

## Objects
- Root nodes: DG Vision; Your DG Framework; Funding and Executive Support
- Branch 1: Definition of Key DG Terms for the Company
- Branch 2: Goals of the DG Program (business value drivers; data pain points; metrics of effectiveness and team/individual year targets)
- Branch 3: Data Prioritization (classification by domains; data access rights matrix)
- Branch 4: Operational Program Management Model (role model — data owners, stewards, stakeholders; governance bodies and project management; operational monitoring tools)
- Branch 5: Cost-Benefit Model of the Program
- Branch 6: DG Processes and Responsibility Matrix
- Branch 7: High-Level DG Policy (normative documentation system)
- Branch 8: List of Priority DG Directions/Initiatives
- Branch 9: DG Technology Stack (data catalog; data quality solution; other DG tools)
- Branch 10: Communication and Marketing System (portal, newsletters, etc.)
