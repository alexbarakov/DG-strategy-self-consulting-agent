## Summary
The data catalog is the most talked-about DG element in tech companies; teams typically find resources to build one with integrations (lineage, metadata fulfillment, data check statuses, Git integration, PII tagging). Open-source refinement dominates — DataHub leads with ~70% adoption; tools must support a push approach and have a strong contributor community. Two critical counterpoints: (1) platform teams use the catalog as a shield to avoid harder governance work (role structures, ownership, domains, glossary/semantic layer, golden layer, data check coverage, data contracts); (2) some argue a catalog isn't strictly necessary — chat-based data management works, but only in isolated domains with minimal cross-functional data usage.
