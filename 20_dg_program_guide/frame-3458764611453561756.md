## Summary
A "Data & Analytics Platform Architecture Template" for AS IS analysis of the data/analytics landscape. Goal: assess the current state of data analytics platforms for harmony, identify duplication cases and development options. The template lays out a modern data platform in six columns (Sources → Ingestion and transport → Storage → Query and Processing → Transformation → Analysis and Reporting) plus a cross-cutting Governance row, with example vendor names per block and suggested usage metrics (number of users, queries, pipelines, reports) per column. It also splits the landscape into "Analytics Platform" vs "Data Platform" zones and links to an Excel version of the template.

## Objects
- Six architecture columns: Sources (ERP, SalesForce, OLTP Databases, Event Collectors, File Storage); Ingestion and transport (Data replication — Fivetran/Airbyte, Workflow manager — Airflow, Event streaming — Confluent/Kafka, Reverse ETL); Storage (Data Warehouse — Snowflake/BigQuery/Redshift, Data Lake — Delta/Iceberg, "Lakehouse" label); Query and Processing (Spark Platform, SQL Query Engine — Dremio/Trino/Presto, DS/ML Platform, Real-time analytics Database — Clickhouse, Stream Processing — Flink/Confluent/Databricks); Transformation (Metrics Layer — dbt metrics/LookML, Data Modeling — dbt, Workflow manager — Airflow); Analysis and Reporting (Reports — Tableau/PBI/Looker, DS/ML Tooling — Databricks/DataRobot, Custom Applications)
- Governance row: Data Quality (Ataccama), Data Governance (Alation, Collibra), Security, DevOps (Git), Analytics Governance, Analytics Delivery
- Suggested per-column assessment metrics: number of users; amount of data/objects; number of queries and tables used; number of active pipelines/models; number of active users and active reports
- Zone labels: "Analytics Platform" and "Data Platform"
- Purple sidebar with Goal statement; "Back to the board" pointer
